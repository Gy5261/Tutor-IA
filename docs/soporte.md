# Soporte

| Problema | Comprobación |
| --- | --- |
| Descargaste un ZIP | Descarga el instalador `.exe`, no “Source code” |
| No puedes entrar | Revisa internet, la cuenta Google y el mensaje de acceso |
| La IA no responde | Revisa permiso, cuota y estado del servicio |
| La búsqueda falla | Puede haber bloqueo de una fuente; revisa el resultado parcial |
| Una herramienta falla | Comprueba el modo de permisos y si la ejecución está pausada |
| No aparece la actualización | Comprueba versión, conexión y si usas portable |
| Descarga dañada o aviso de firma | Sigue la [verificación](actualizaciones.md#verificar-descarga); no desactives protecciones |

## Reportar

Abre una [incidencia](https://github.com/Gy5261/Tutor-IA/issues/new) con versión de Tutor-IA y Windows, pasos, resultado esperado y mensaje visible.

Oculta datos personales y contenido privado. No adjuntes perfiles, bases de datos, sesiones, claves ni conversaciones.

Permisos de cuenta, solicitudes sobre datos y vulnerabilidades se tratan por un canal privado con el responsable del proyecto. Consulta [seguridad](../SECURITY.md).
