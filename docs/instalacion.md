# Instalación

Tutor-IA 6.1.8 se distribuye para Windows x64. El acceso con Google, la IA remota y las actualizaciones requieren internet.

1. Abre la [release oficial](https://github.com/Gy5261/Tutor-IA/releases/latest).
2. Descarga `Tutor-IA-Setup-6.1.8.exe`.
3. [Verifica el archivo](actualizaciones.md#verificar-descarga), instálalo y abre Tutor-IA.
4. Inicia sesión con Google.

El instalador no tiene firma Authenticode. No desactives las protecciones de Windows.

“Source code” no instala la aplicación. Este repositorio no ofrece instalación mediante npm ni versiones para macOS o Linux.

## Portable y datos

El portable se actualiza descargando la nueva versión manualmente. Para usar el canal de actualización automático, instala la edición Setup.

No borres el perfil para migrar, reinstalar o resolver errores. La desinstalación puede conservar datos locales y no elimina registros remotos; consulta [privacidad](../PRIVACIDAD.md).
